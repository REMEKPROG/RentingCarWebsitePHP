# 🚗 Dynamic Vehicle Rental Website

A dynamic web application for a vehicle rental service that allows users to:
- browse available vehicles by category,
- reserve vehicles,
- return rented vehicles.

Built using **HTML, CSS, PHP**, and **JavaScript**.

## 📌 Features

- 🔍 **Browse Vehicles** – filter vehicles by category (e.g., passenger cars, vans, SUVs).
- 📅 **Vehicle Reservation** – reservation form with validation.
- 🔄 **Vehicle Return** – return system with availability updates.
- 🖥️ **Dynamic Content** – data is loaded and stored using PHP and MySQL.

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: PHP 7+
- **Database**: MySQL (via PHP)
- **Others**: AJAX for server communication
